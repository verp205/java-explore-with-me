# ExploreWithMe (EWM) 📍 — Гид по событиям

**ExploreWithMe** — это микросервисное приложение, которое позволяет пользователям делиться информацией об интересных событиях, находить компанию для их посещения и отслеживать статистику просмотров.

Этот проект представляет собой полноценную платформу с разделением прав доступа (пользователи/администраторы) и автоматизированным сбором статистики.

---

### 🏗️ Архитектура системы

Приложение разделено на два независимых сервиса, взаимодействующих через REST API:

1.  **Main Service (Основной сервис):**
    * Содержит всю бизнес-логику.
    * Управление пользователями, событиями, категориями и подборками.
    * Обработка запросов на участие в событиях.
2.  **Stats Service (Сервис статистики):**
    * Регистрирует каждый просмотр события.
    * Предоставляет данные о посещаемости для основного сервиса.
    * Использует отдельную базу данных для оптимизации хранения логов.

---

### 🛠️ Технологический стек

Проект построен на современном стеке Java-разработки:

* **Core:** Java 11+, Spring Boot.
* **Data:** Spring Data JPA, Hibernate, PostgreSQL.
* **API:** REST, JSON, Postman (для тестирования).
* **Infrastructure:** Docker, Docker Compose (мультиконтейнерная сборка).
* **Tools:** Maven, Lombok, MapStruct (для маппинга DTO).
* **Quality:** JUnit, Checkstyle.

---

### 🚀 Как запустить проект

Для запуска вам понадобится установленный **Docker** и **Docker Compose**.

1. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/verp205/java-explore-with-me.git](https://github.com/verp205/java-explore-with-me.git)
   cd java-explore-with-me
   ```

2. Соберите проект и запустите контейнеры:
   ```bash
   mvn clean package -DskipTests
   docker-compose up
   ```

3. После запуска будут доступны:
   * **Main Service:** `http://localhost:8080`
   * **Stats Service:** `http://localhost:9090`
   * **Postgres (Main):** портал базы данных 5432
   * **Postgres (Stats):** портал базы данных 6432

### 📋 Функциональные возможности

#### Для пользователей (Private API):
- Добавление собственных событий и управление ими.
- Подача заявок на участие в чужих мероприятиях.
- Просмотр своих заявок и статусов.

#### Для всех (Public API):
- Поиск событий по фильтрам (даты, категории, платно/бесплатно).
- Просмотр подробной информации о событии (с фиксацией просмотра в статистике).

#### Для администраторов (Admin API):
- Модерация событий (публикация или отклонение).
- Управление категориями событий.
- Работа с базой пользователей.
